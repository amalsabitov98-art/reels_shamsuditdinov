# Reels Studio

Отдельная Reels-часть из `agent-lite-main`: без сайта с гайдами, Hiker API,
автоворонки, Telegram-бота и обязательной подписки Claude.

Интерфейс размещается на GitHub Pages, а монтаж выполняется на вашем Windows-компьютере.
Компьютер нужен только пока идёт обработка. Покупать отдельную машину или сервер не нужно.

## Что умеет

- принимать исходное вертикальное видео через сайт;
- локально расшифровывать речь и резать видео по границам фраз;
- создавать и редактировать спек раскадровки;
- генерировать сториборды через ваш вход в ChatGPT;
- вручную назначать скачанные результаты Flow номерам частей, просматривать и собирать MP4;
- проверять наличие звука, длительность, целостность и порядок выбранных файлов;
- расшифровывать финальную речь для ручной сверки (не подтверждение её точности).

Браузерная автоматизация ChatGPT/Flow экспериментальная. Совместимость с новым
интерфейсом Flow «Агент» не подтверждена. Автоскачивание по времени отключено:
оно могло привязать результат не к той части. Платный API не подключался.

## Обновление до 1.1

Закройте окно START.bat, сохраните копию текущей папки проекта. Распакуйте
`reels-studio-1.1.zip` **в существующую папку рядом с START.bat**, соглашаясь
на замену файлов кода. Не удаляйте старую папку: в ней ваши `workspace`, `auth`
и `.venv`. Архив обновления их не содержит. Запустите START.bat и обновите сайт
через Ctrl+F5. Если браузер не разрешает доступ к локальному движку, откройте
`http://127.0.0.1:3210/` — тот же интерфейс обслуживается с компьютера.

Для существующей установки новые зависимости не нужны. VS Code/Visual Studio не нужны.

## Как получить MP4 без автоматических кликов Flow

1. Выберите подготовленный проект. Существующие раскадровки не пересоздавайте.
2. Создайте/проверьте результат каждой части в Flow, скачайте MP4 со звуком.
   PNG-раскадровка и исходный `rN-snd.mp4` — не готовый смонтированный результат.
3. В разделе «Готовые части из Flow → MP4» выберите файл для каждого номера.
   Посмотрите предпросмотры, сверяясь с текстом части.
4. Подтвердите порядок и речь, нажмите «Собрать выбранные части», затем «Скачать MP4».

Результат: 1080×1920, 30 кадров/с, звук выбранных результатов Flow.
Пропорции сохраняются с полями при необходимости, без растягивания и маскировки
водяных знаков. Речь не подменяется на оригинальную. Допуск длительности части —
0.6 с или 10%; иначе импорт просит проверить файл. Техническая проверка не
доказывает, что Flow правильно произнёс слова или нарисовал текст.
Предыдущие импорты, финалы и временные файлы сохраняются — следите за местом на диске.

## Диагностика Flow

Нажмите «Открыть Flow», войдите в один проект в специальном Chrome, оставьте окно
открытым. Нажмите «Диагностика Flow», затем «Скачать отчёт».
Диагностика не кликает, не отправляет запросы генерации и не читает cookies/пароли.
Отчёт содержит URL проекта и подписи кнопок (возможны названия файлов); просмотрите
его перед отправкой. Один такой отчёт нужен для дальнейшей адаптации интерфейса.

## Что проверено

См. `RELIABILITY.md`: отдельно указаны тесты файловой сборки, ограничения
браузерного режима и проверки, ещё не выполненные на Windows/в аккаунте Flow.

## Первый запуск на Windows

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте в папку без
   русских букв, например `C:\reels-studio`.
2. Дважды нажмите `INSTALL.bat`. Он поставит недостающее и подготовит проект.
3. Дважды нажмите `START.bat`. Откроется сайт и маленькое окно локального движка.
4. Не закрывайте окно движка и окна Chrome, пока собирается ролик.

После первой установки дальше нужен только `START.bat`.

## Деньги

Код проекта и локальная обработка не требуют отдельного API. Лимиты и оплата
ChatGPT/Flow зависят от аккаунта и текущих условий сервисов. Материалы при генерации
передаются этим сервисам, а не остаются только на компьютере. API-ключ OpenAI не требуется.

## Если сайт пишет «движок не подключён»

- запустите `START.bat`;
- попробуйте локальный интерфейс `http://127.0.0.1:3210/`; не отключайте брандмауэр;
- не открывайте сайт в режиме инкогнито;
- проверьте `http://127.0.0.1:3210/health` — должна открыться строка с `ok: true`.

Подробный порядок отображается прямо на сайте.
