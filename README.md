# Reels Studio

Отдельная Reels-часть из `agent-lite-main`: без сайта с гайдами, Hiker API,
автоворонки, Telegram-бота и обязательной подписки Claude.

Интерфейс размещается на GitHub Pages, а монтаж выполняется на вашем Windows-компьютере.
Компьютер нужен только пока идёт обработка. Покупать отдельную машину или сервер не нужно.

## Что умеет

- принимать исходное вертикальное видео через сайт;
- локально расшифровывать речь и резать видео по границам фраз;
- создавать и редактировать спек раскадровки;
- генерировать сториборды через ваш вход в ChatGPT;
- загружать материалы и ставить монтаж в очередь Google Flow;
- скачивать части, собирать финальный MP4 и проверять речь.

## Первый запуск на Windows

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте в папку без
   русских букв, например `C:\reels-studio`.
2. Дважды нажмите `INSTALL.bat`. Он поставит недостающее и подготовит проект.
3. Дважды нажмите `START.bat`. Откроется сайт и маленькое окно локального движка.
4. Не закрывайте окно движка и окна Chrome, пока собирается ролик.

После первой установки дальше нужен только `START.bat`.

## Деньги

Сам проект, GitHub Pages, FFmpeg и локальная расшифровка бесплатны. Google Flow
сейчас даёт бесплатные ежедневные кредиты; их количество и доступность зависят от
аккаунта и страны. ChatGPT используется через уже выполненный вход в браузере,
API-ключ OpenAI не требуется.

## Если сайт пишет «движок не подключён»

- запустите `START.bat`;
- разрешите Node.js доступ в брандмауэре только для частных сетей;
- не открывайте сайт в режиме инкогнито;
- проверьте `http://127.0.0.1:3210/health` — должна открыться строка с `ok: true`.

Подробный порядок отображается прямо на сайте.
