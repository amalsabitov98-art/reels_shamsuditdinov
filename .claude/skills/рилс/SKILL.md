# Reels Studio

Основной интерфейс находится на GitHub Pages. Тяжёлые операции выполняет локальный
движок `scripts/helper-server.mjs`, запущенный через `START.bat`.

```
исходник → локальная расшифровка → нарезка 8–10 с → сториборды ChatGPT
         → монтаж Google Flow → сборка FFmpeg → сверка речи
```

## Порядок

1. Пользователь загружает MP4/MOV/WEBM на сайте. Не проси Telegram-бот или Hiker API.
2. `split-video.py` создаёт `workspace/reels/<slug>/project.json`, части и
   `sb-spec.json`. Не режь слово посередине и не делай часть длиннее 10 секунд.
3. Перед сторибордами пользователь один раз открывает ChatGPT кнопкой на сайте и
   входит в аккаунт. `storyboard-batch.mjs` подключается к Chrome на порту 9222.
4. Перед монтажом пользователь открывает Flow, входит и создаёт пустой проект.
   `run-flow.mjs` загружает борды и части, ставит задачи последовательно, скачивает
   результаты и собирает `final.mp4`.
5. Финал проверяется `transcribe.py --txt`. Если есть пропуск или повтор слов,
   результат не считать готовым.

## Жёсткие правила промптов

- цвет описывать словами, без hex-кодов;
- тайминг описывать словами, без числовых таймкодов;
- один короткий заголовок на экране одновременно;
- никаких списков, логов, таблиц, мелкого текста и подписей панелей;
- звук в финале по умолчанию оставлять от Flow;
- части загружать только со звуком;
- режим Flow перед каждой генерацией должен быть `Ingredients`.

Стиль находится в `styles/kinetik.md`. Секреты, браузерные профили, исходники и
готовые видео никогда не коммитить.
