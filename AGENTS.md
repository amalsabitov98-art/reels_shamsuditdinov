# Reels Studio

Этот репозиторий содержит только Reels-конвейер из Agent Lite. Пользователь работает
через интерфейс GitHub Pages, а `scripts/helper-server.mjs` выполняет тяжёлые операции
локально на Windows.

При запросе «собери рилс»:

1. Проверь `workspace/reels/<slug>/project.json` и `sb-spec.json`.
2. Не публикуй и не загружай ролик куда-либо без прямой просьбы пользователя.
3. Не коммить `auth/`, исходные видео, результаты, токены и браузерные профили.
4. Части должны быть по 8–10 секунд и со звуком.
5. Перед Flow прочитай `styles/kinetik.md` и `.claude/skills/рилс/SKILL.md`.
6. После сборки обязательно запусти расшифровку финала и сообщи о расхождениях.

Скрипты должны оставаться переносимыми: никаких путей вида `D:/...` или профилей,
зашитых под конкретный компьютер.
